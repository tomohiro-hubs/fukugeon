# 法人向け電気通信工事会社 コーポレートサイト

「技術力 × スピード」をテーマにした、B2B向け1ページ完結型コーポレートサイトです。

## プロジェクト概要

*   **目的**: 法人案件（元請、店舗運営企業など）の新規問い合わせ獲得
*   **ターゲット**: 設備担当、施工管理、総務などの発注担当者
*   **コンセプト**: 「技術で解決。スピードで前に進める。」
*   **主要機能**: サービス紹介、強み訴求、実績表示、FAQ、お問い合わせフォーム

## ファイル構成

```
/
├── index.html        # メインページ（全セクションを含む）
├── css/
│   └── style.css     # カスタムスタイル、アニメーション調整
└── js/
    └── main.js       # モバイルメニュー、FAQ、スクロール制御
```

## 使用技術・ライブラリ

*   **HTML5 / CSS3 / JavaScript (Vanilla)**
*   **Tailwind CSS**: スタイリングとレスポンシブデザイン
*   **Font Awesome**: アイコン表示
*   **Google Fonts**: タイポグラフィ (Noto Sans JP, Inter)
*   **AOS (Animate On Scroll)**: スクロール時のフェードインアニメーション

## 主なセクション

1.  **Header**: 固定ナビゲーション、お問い合わせCTA
2.  **Hero**: ファーストビュー、タグライン、メインCTA
3.  **Services**: 事業内容（電気通信、内装、空調）
4.  **Strength**: 選ばれる3つの理由（Speed, Skill, One-stop）と品質の約束
5.  **Area**: 対応エリア（神奈川・愛知）の視覚的表現
6.  **Works**: 実績紹介とKPI表示
7.  **Flow**: ご依頼の流れ
8.  **FAQ**: よくある質問（アコーディオン形式）
9.  **Contact**: お問い合わせフォーム

## カスタマイズについて

*   **ロゴ**: 現在はFontAwesomeのアイコンをプレースホルダーとして使用しています。画像ファイルに差し替える場合は、`header`内の `i`タグを `img`タグに変更してください。
*   **画像**: Heroセクションの背景画像はUnsplashのURLを使用しています。必要に応じて実写の現場写真などに差し替えてください。
*   **地図**: エリアセクションの地図はCSSで描画されています。より詳細な地図が必要な場合は画像を作成して差し替えてください。

## デプロイ

「公開」タブをクリックするだけで、即座にWebサイトとして公開されます。
